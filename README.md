# Sistema de Control de Rescate y Adopción — UTM

Prototipo académico estructural realizado con HTML5 semántico, sin CSS ni JavaScript.

## Archivos
- `index.html`: página principal.
- `reportar.html`: formulario de reporte.
- `rescates.html`: tabla de casos de ejemplo.
- `assets/img/`: carpeta reservada para imágenes.

## Vista local
Abre `index.html` en un navegador y utiliza el menú para visitar las otras páginas.

## Importante
Los casos de `rescates.html` son datos demostrativos. El formulario no guarda datos, ya que esta actividad pide una maqueta estructural HTML5.

## Gitflow requerido
Crear y trabajar en `feature/maquetacion-html`, validar los tres HTML en el validador W3C y luego integrar la rama en `develop`.
